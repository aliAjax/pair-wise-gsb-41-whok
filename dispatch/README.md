# 台风灾后查勘排程台

台风过后查勘员派工控制台。纯 HTML/CSS/JavaScript，**零依赖、无构建步骤**，直接用浏览器打开 `index.html` 即可使用。数据保存在浏览器 localStorage，**重开页面后任务、人员与变更记录仍在**。

## 分层（排程 / 保存 / 页面 分开）

| 文件 | 职责 |
| --- | --- |
| `js/scheduler.js` | 排程层：案件排序（事件→区域→损失）、派工/改派校验，纯函数 |
| `js/store.js` | 保存层：状态、localStorage 持久化、变更记录（audit），所有数据改动都经此层 |
| `js/app.js` | 页面层：渲染与交互，不直接改数据 |
| `index.html` / `css/style.css` | 页面骨架与样式 |

## 业务规则

- **案件排序**：待派区按 事件 → 区域 → 损失（高在前）排序。
- **人员**：登记查勘员、班次（日期+起止时间）与高风险资质。
- **留派原因**：派工/改派时出现以下任一情况，案件留在待派区并写明原因（同时记入变更记录）：
  - 任务撞车：与同一查勘员当日已有任务时间重叠；
  - 跨区赶场不足 90 分钟：与不同区域的相邻任务间隔 < 90 分钟；
  - 资质不符：高风险案件派给未登记高风险资质的查勘员。
- **到场**：到场必须登记灾损与风险两条记录；一般案件随即完成，高风险案件进入待复核。
- **复核与预付**：高风险案件须由具备高风险资质且非承办人的复核人确认后，才能继续预付；规则在保存层二次校验，绕过页面也无效。
- **释放班次**：改派或取消立即释放班次（校验只统计未取消任务），案件回到待派区等待重派。
- **可追溯**：每个任务带变更轨迹，全局有变更记录，全部持久化。
